# EcommerceCart

EcommerceCart is a full-stack ASP.NET Core MVC e-commerce application that allows users to browse products, manage shopping carts, and raise complaints, while administrators can manage products and customer support requests.

## Features

### Customer Features
- User Registration and Login
- Browse Products
- Add Products to Cart
- Update Product Quantity
- Remove Products from Cart
- View Cart Total
- Submit Complaints
- Track Complaint Status
- Contact Support

### Admin Features
- Secure Admin Login
- Create New Products
- Update Existing Products
- Delete Products
- View Customer Complaints
- Update Complaint Status
- Manage Product Catalog

## Technology Stack

- ASP.NET Core MVC
- C#
- Entity Framework Core
- SQL Server
- Bootstrap
- HTML5
- CSS3
- JavaScript
